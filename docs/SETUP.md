# Setup

## Brain (already done on this Mac)

```bash
cd brain
python3 -m venv .venv
.venv/bin/pip install -e .
.venv/bin/pytest
```

Real agents need a key:

```bash
export ANTHROPIC_API_KEY=sk-ant-...
```

Optional env vars (see `brain/hearth/config.py`):

| Var | Default | Meaning |
|---|---|---|
| `HEARTH_MODEL` | `claude-opus-5` | Model for agent decisions |
| `HEARTH_EFFORT` | `low` | `low`/`medium`/`high` — decision depth vs. cost |
| `HEARTH_FALLBACKS` | `0` | `1` enables Anthropic server-side refusal fallbacks (beta) |
| `HEARTH_WS_PORT` | `8765` | WebSocket port for Unreal |

## Unreal Engine (installed: UE 5.8.2, Xcode 26.6, Metal Toolchain)

The project compiles and the Valley map is generated by script. See `unreal/README.md` for the
command-line workflow. To watch:

```bash
cd brain && .venv/bin/python -m hearth run --brain claude --voice say --tick-seconds 8
open unreal/Hearth/Hearth.uproject      # then press Play
```
